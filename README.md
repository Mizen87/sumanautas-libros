# Sumanautas · Biblioteca

Cuentos originales para la Librería de Puerto Suma del juego **Sumanautas**. Cada semana se añade uno por nivel
(peques 4-6, exploradores 7-10 y aventureros 11+): texto escrito y revisado con IA, ilustraciones y narración en
castellano e inglés. El juego descarga `catalogo.json` y los libros nuevos de `libros/<id>/`.
